# 🔐 GUI Password Generator

A simple and clean desktop application built with Python and Tkinter to generate secure, random passwords.

---

## 🌟 Features
- Custom password length selection (4 to 64 characters).
- Combines letters, digits, and special characters for maximum security.
- One-click copy to clipboard functionality.
- Input validation and error handling popups.

---

## 🛠️ Tech Stack
- **Language:** Python 3
- **GUI Library:** Tkinter (Built-in)
